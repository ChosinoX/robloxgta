# Costa Verde — Roblox open-world starter

An original, GTA-inspired (not affiliated with Rockstar Games) open-world Roblox prototype. It creates a streaming city, countryside, mountain range, roads, pedestrians, traffic, four selectable vehicles, persistent cash, and an optional shop entirely from Luau.

## Open in Roblox Studio

1. Install [Rojo](https://rojo.space/) and run `rojo serve` in this directory.
2. Open a new Baseplate in Roblox Studio and connect with the Rojo plugin.
3. Press **Play**. The world is generated by `WorldBuilder` when the server starts.
4. Publish the experience before testing DataStores or purchases.

## Controls

- **G** or **Garage** opens vehicle selection.
- Standard Roblox vehicle controls: **W/S** accelerate/reverse and **A/D** steer.

## Monetization setup

All product IDs default to `0`, so Studio cannot accidentally sell a placeholder product. Create developer products and game passes in Creator Dashboard, then insert their IDs in `src/shared/Config.lua`. `ProcessReceipt` awards developer-product cash on the server, and premium-car ownership is checked server-side. Keep the products optional and clearly priced; do not gate the core map or starter cars.

## Architecture

- `WorldBuilder.lua` procedurally constructs the map, keeping the repository lightweight.
- `VehicleService.lua` creates and drives arcade-style cars.
- `NPCService.lua` populates ambient pedestrians and traffic.
- `Main.server.lua` owns remotes, saves cash, validates vehicles, and grants purchases.
- `Main.client.lua` supplies the responsive garage, HUD, cash display, and purchase prompt.

For a production launch, replace generated blocks with optimized authored assets, add proper wheel suspension/navigation paths, turn on API Services for Studio DataStore testing, and test mobile/gamepad UI in Device Emulator.
